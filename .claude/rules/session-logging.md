# Session Logging

**Location:** `quality_reports/session_logs/YYYY-MM-DD_description.md`
**Shape** (as in the existing logs): `# Session Log: date — topic`, then `## Goal`, `## Done today`, `## Open`, `## Learnings`, `## End of session`.

- **Start:** once the task is agreed, write the goal and key context.
- **During:** append 1–3 lines when a decision is made, a problem is solved, the user corrects something, or the approach changes.
- **End:** summary, what's open, and any `[LEARN]` lines (copy generic ones to `MEMORY.md`).
- Skip the log for quick one-off questions.
